# Rastgele Absürt Tavsiye Jeneratörü

## Bu Ne Lan?

Bu, insanlığın en büyük sorunu olan "ne yapacağımı bilmiyorum" durumunu çözmek için tasarlanmış, dünyanın en ciddiye alınan saçma projesi.

Gerçekten çalışır. Gerçekten saçmadır. Gerçekten kullanışsızdır.

## Nasıl Çalışır?

1. Python 3 yükle (yoksa internetten indir, belki de patatesle yapma).
2. `python3 absurt_tavsiye.py` yaz.
3. Ekrana bak. Gül. Uygulama. Pışman ol.
4. Tekrar çalıştır. Sonsuza kadar devam et.

## Neden Var?

Çünkü dünya zaten yeterince ciddi. Birinin de saçmalaması lazım. O biri biziz.

Bu proje, özgürlüğün en saf hali olan "kaşığı ters tutma" felsefesini kod haline getirmiştir. Kimse anlamasa da olur. Anlayan anlar.

## Özellikler

- %100 gerçek Python.
- %0 mantık.
- Sonsuz tekrar edilebilir.
- Gizli mesajlar içerir (bulursan tebrikler).
- Patatesle hiçbir ilgisi yoktur.

## Katkıda Bulunma

Katkıda bulunma. Bu proje zaten mükemmel. Bozma.
